# 1.3.0 交战性能与战术玩法预览

本次更新直接修改 `addon-src/`，只更新 Enemy Forces 附属及其参考配置。仓库内修改版 Superb Warfare 和 DragonRise 的 JAR 保持原样。

## 交战负载

- 每维度每 tick 共用载具、弹药、额外目标的空间索引，减少各单位独立遍历整个维度。
- 非制导弹药对友军的威胁预测每 5 tick 共用一次；同目标在途导弹上限继续保留。
- 实体快照仅在登记集合改变时重新分配；客户端告警和战术面板共用导弹登记。
- 默认每 tick 最多生成 32 发附加 AI 弹药，保留最多 512 个活跃附加弹体，并为紧急防空预留 8 个额外额度。额度不会通过删除玩家弹药来腾出。
- 附加 AI 弹药默认不申请区块加载，并在进入未加载战场前结束；玩家导弹保留原模组行为。需要跨区块远程空战时可打开 `aiProjectileChunkLoading`。
- 寿命清理默认只管理附加弹药；不会把原版箭、三叉戟等所有 `Projectile` 统一清理。
- 地图更新按有限队列片段筛选；后台写盘合并同世界、瓦片和区块的更新，保留最新值。队列限制为 8192 个待写区块及配置的字节额度，写入背压时生产方保留数据等待下次提交。
- F-16 的逐架 INFO 状态日志默认关闭，`/f16addon perf` 增加清理、F-16、地面、防空耗时细分。

## 战斗节奏

| 单位 | 默认附加弹药 | 节奏 |
| --- | --- | --- |
| BMPT | 120 发 | 每 6 tick 一发，6 发后暂停 40 tick |
| T-80 | 18 发 | 每次主炮后装填 50 tick |
| 黄蜂 | 6 枚 | 沿用防空射击间隔，耗尽后等待补给 |
| F-16 | 240 发机炮，各 4 枚近距弹、雷达弹、对地弹、炸弹 | 机炮 12 发后冷却；没弹的武器让位给其他适用武器 |

这里采用保存到实体 NBT 的**虚拟 AI 弹药**，不从原生物品栏扣除，也没有新增补给方块或资源消耗。地面单位耗尽后返回部署点 24 格内；飞机返回默认 128 格内，连续服务 200 tick 后恢复弹药。飞机能源默认只在部署点附近补充，没有重做其燃油物理。

生命低于 30% 时撤退，恢复到 45% 才重新参战；修复生命仍由载具原有机制处理。`groundmode stop` 保持停止指令。

地面兵种按角色选择目标，T-80 偏向载具、BMPT 偏向轻目标。默认由附加逻辑统一控制开火；`groundNativeWeapons=true` 时，有 Mob 乘员的地面单位切回原生武器，其射速和库存不受虚拟弹药系统控制。玩家驾驶时仍可使用原生乘员武器。

## 爆炸

- 附加 BMPT、T-80 爆炸半径默认改为 2.5 / 6.0，直击伤害保持原数值；附近范围伤害随半径调整。
- F-16 机炮爆炸半径默认 1.5；直接生成的近距弹显式设置伤害，避免依赖枪械发射路径才填充的数据。相关参数均可调整。
- `preserveTerrain=true` 时，在 SBW 自定义爆炸的 `explodeBlocks()` 入口跳过带标记 AI 弹药的地形扫描，实体伤害继续执行。弹体直接命中或其他特殊破坏路径仍可能改动方块。
- 客户端默认 96 格内保留完整爆炸粒子，96–256 格使用小型效果，更远保留微型闪光；每 tick 最多 3 个详细爆炸。该视觉设置作用于 SBW 粒子入口，包含玩家爆炸；不修改伤害与音效。

## 时钟和生命周期修复

原威胁索引、RWR 用 `Long.MIN_VALUE` 初始化上次扫描时间，然后直接做减法，首次扫描会因整数溢出被跳过。现在显式处理首次调用、时间回退和减法溢出，并在退出世界时释放缓存。

原有近炸钩子保留，同时兼容实际存在的安全出膛检测。Mixin 选择器同时包含开发映射名称和生产 SRG 名称。

## 战术任务

OP 2 级权限可用：

```text
/f16addon encounter start
/f16addon encounter status
/f16addon encounter stop
/f16addon resupply
```

每维度最多一场任务，先生成 1 台黄蜂、1 辆 T-80 和 1 辆 BMPT。摧毁黄蜂后增援 1 架 F-16，全部击败获得 200 点经验。任务进度保存到世界；未加载的单位不算已击败，任务不强制加载区块。开始任务要求附近有足够已加载的安全地面。

`encounter stop` 结束目标记录，保留已经生成的敌军。`resupply` 补满附近 512 格内附加单位的虚拟弹药。

## 配置与构建

服务端参数新增于 `<存档>/serverconfig/f16addon-server.toml` 的 `[combatTuning]`，参考文件为 `config/f16addon-server.toml`。客户端配置位于 `config/f16addon-client.toml` 的 `[effects]`。原有服务端参数保持现有值，缺少的新键会自动补充。

常用开关：

- `finiteAmmo=false`：关闭虚拟弹药限制和对应返回补给。
- `retreatHealthFraction=0`：关闭低血量撤退。
- `aiProjectileChunkLoading=true`：允许附加 AI 导弹沿用主动加载区块。
- `preserveTerrain=false`：恢复原生爆炸地形扫描。
- `explosionLod=false`：关闭客户端粒子分级。

弹药寿命是清理上限，原修改版的硬寿命和失锁逻辑仍可能先结束飞行，例如现有 9M336 的 160 tick 限制。

```sh
cd addon-src
./gradlew build coreRegression
```

使用仓库现有 Java 17、Forge 47.4.0、Gradle Wrapper，以及 `../mods/` 中的修改版依赖。产物为 `addon-src/build/libs/enemyforces-1.3.0-source-preview.jar`。

## 验证范围

基于 `main` 的 `8fa90a3` 提交，使用 Java 17、Gradle 8.8 和 Forge 47.4.0 验证：

- `./gradlew build coreRegression`：编译、JAR 生成、生产重混淆全部通过；229 项核心与真实地图 IO 断言通过。
- `python3 tests/check_mixin_contracts.py`：仓库内修改版 SBW 与 DragonRise 的 64 项方法选择器和字段合约全部通过，没有未核对目标。
- 预览 JAR 全部 class 使用 Java 17 字节码；已核对 Mixin 资源和版本。
- 两个第三方修改版 JAR 的 SHA-256 与基线一致，未改写它们。

核心检查覆盖首次时钟扫描、空间查询不漏目标、威胁方向、点射、粒子分级，以及真实磁盘缓存合并、负坐标和世界隔离。Mixin 合约检查核对目标存在性，不等于完成游戏运行时注入测试。

这次不声称已经测出新的帧率或 MSPT 提升，也没有完成完整三模组客户端、专用服务器和多人交战实测。旧版本性能数字仅作为历史记录。
